## Full description

SetPilot is a strength log for people who already know the workout. Open an exercise and the last weight and reps are waiting. Confirm a set with one tap, change the load only when it changed, and the rest timer starts on its own.

Save routines, swap an exercise when a machine is taken, copy a past workout, and see how each lift is moving. Export the log when you want a copy.

The logging screen uses large type and keeps the confirm button at the bottom, so it works with one hand.

Looks, keep-screen-on, tap feedback, and SetPilot Pro (more than 8 routines) unlock with coins from finishing a workout or 10 coin packs. Remove ads and SetPilot Pro are one-time unlocks.
